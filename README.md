# 初中一年级英语词表研习系统 (沪教版/新牛津 7A · 2024新版)

基于 SuperMemo-2 (SM2) 间隔重复算法与 Notion 极简设计规范构建的高效学术背诵工作台。

## 特性

- **完整词库**：收录 2024 新教材 7A 全套 8 个单元全部考纲词汇（共 169 词），含音标、词性、释义与高频考点搭配。
- **SM2 记忆引擎**：经典间隔重复算法，支持连续答对推迟与遗忘即时循环重背。
- **研习热力图**：内嵌过去 150 天研习活跃度热力图与学情矩阵。
- **成就勋章系统**：10 阶梯级学术勋章画廊，记录背诵里程碑。
- **难词强制停留机制**：对 $EF < 2.2$、初学阶段或曾遗忘词汇强制锁定 4 秒，防止浅层刷题。
- **双引擎高清发音**：支持英音/美音切换与翻卡二次发音回响。
- **防盗链与安全头**：内置 Cloudflare Pages `_headers` 与 Worker 防盗链访问限制。
- **离线持久化**：本地进度纯前端 `localStorage` 安全存储，支持完全断网运行。
