# 初中一年级英语词表背诵系统 (沪教版 7A · 2024新课标)

基于 SuperMemo-2 (SM2) 间隔重复算法与 Minimal 极简设计规范构建的学术自学背诵工作台。

## 特性

- **官方 2024 新课标词库**：收录 2024 新教材 7A 全套 8 个单元全部官方考纲单词（256 词）与重点课文短语（71 条），总计 327 条，含国际音标、官方词性、准确释义与教材课文例句。
- **模块化架构**：核心分离为独立数据文件（`data/`）、标准样式表（`css/`）与 ES6 模块化引擎（`js/sm2.js`, `js/storage.js`, `js/audio.js`, `js/app.js`）。
- **SM2 间隔重复引擎**：经典记忆算法，根据记忆留存度自动计算下一次复习周期与难度系数。
- **4秒自然沉淀**：翻开卡片后按钮内置 4 秒锁定期，杜绝浮躁浅层刷题，确保发音沉淀与深度理解。
- **重点难词复习**：对多次遗忘词汇（遗忘次数 ≥ 4）自动归入重点难词库，强化形态拆解与考点搭配。
- **双通道高清发音**：支持英音/美音切换与二次朗读回响。
- **学习记录热力图**：呈现过去 150 天每日复习活跃度与掌握度矩阵。
- **离线持久化**：本地进度纯前端 `localStorage` 安全存储，支持断网离线运行。
