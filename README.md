# 2024新课标沪教版初中英语全学段研习工作台 (7A - 9全册 · V3.0)

基于 SuperMemo-2 (SM2) 间隔重复算法与 Notion Minimal 极简设计规范构建的初中全学段英语词汇与考点研习工作台。

线上访问地址：[https://english.yunet.cfd](https://english.yunet.cfd)

## 核心特性

- **2024 新课标全学段完整覆盖**：
  - 完整收录 **七年级上册 (7A)**、**七年级下册 (7B)**、**八年级上册 (8A)**、**八年级下册 (8B)** 及 **九年级全册 (9A/9B)** 全部 38 个单元官方词库与单元核心短语。
  - 严格双层分类：每一单元清晰区分 **【课内必背核心词】(Curricular Core)** 与 **【课外高分拓展词】(Extracurricular Expansion)**，支持独立筛选与双轨混合背诵。
- **持久化引擎 3.0 (Zero Data Loss Architecture)**：
  - **规范化全局卡片 ID**：支持 `${book}_u${unit}_${category}_${index}` 全局命名空间。
  - **老用户零丢失平滑升版**：针对既有 7A 老卡片 ID（如 `u1_1`）内置双向兼容解析映射引擎与冷备快照（`sm2_vocab_progress_backup_pre_v3`），老用户历史学习轮次、EF因子与艾宾浩斯间隔 **100% 完整保留**。
  - **三层冗余防线**：`IndexedDB (VocabLearnerDB_Unified)` 权威主库 + `In-Memory` 极速同步缓存 + `localStorage` 双写安全镜像与降级保底通道。
- **SM2 间隔重复引擎**：
  - 经典 SuperMemo-2 算法，根据自测品质（重来/困难/良好/简单）实时推演下一次到期日与成熟度。
  - **2秒翻卡自然沉淀**：未成熟卡片内置 2 秒平滑倒计时锁定期，引导大声朗读与语境拆解；特别熟卡片（连续记对 ≥ 2 次且 EF ≥ 2.4）瞬间可评。
- **多维度学情分析与 AI 量化诊断看板**：
  - 艾宾浩斯稳态分析：实时追踪记忆留存率 (Retention Rate)、单次遗忘率 (Lapse Rate)、积压衰减风险与重点难词负荷。
  - 一键复制或导出结构化 Markdown AI 诊断 Prompt，支持发送给主流大模型定制针对性复习策略。
  - 全量学情备份导出（.json）与跨设备导入无损合并。
- **附录与中考专项速查**：
  - 中考高频核心动词词族（look, take, get, give, put 等）与必背介词固定搭配。
  - 初中英语必背不规则动词分类全表（AAA, ABA, ABB, ABC 型）。
  - 中考核心构词法与词形转换规律（否定前缀、名词/形容词/副词派生后缀）。
- **双通道高清朗读与离线缓存**：
  - 支持英音 (UK) 与美音 (US) 发音切换。
  - 接入 `Cache API` 离线发音缓存网关，纯原生 HTML/CSS/JS 零第三方打包依赖，断网也能流畅使用。

## 运行与测试

```bash
# 语法与模块自检
npm run check

# 持久化引擎平滑迁移与多册数据安全自动化测试
npm test

# 重新编译词库数据 (由 Markdown 生成 JSON)
npm run build:vocab
```
